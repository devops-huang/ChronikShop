# 本地跑起来（10 分钟，零凭证）· Run It Locally (10 minutes, no credentials)

> 目标：在你自己的电脑上跑通 `demo/`，看到 4 份订单 → CSV + 复核页 + 指标。
> 全程不需要 Azure 账号、不需要 API key、不需要联网（装依赖那一步需要联网）。
>
> *Goal: run `demo/` on your own machine and see four orders turn into CSV + a review sheet + metrics. No Azure account, no API key, no network except installing dependencies.*

## 0. 你需要什么 · What you need

- Python **3.9+**（推荐 3.11 / 3.12）。**CentOS 7/8、RHEL 8 自带的 `python3` 是 3.6，不够用。**
- Git
- 大约 300 MB 磁盘（大部分是 PyMuPDF 和 Pillow 的 wheel）

```bash
python3 -V      # Windows: py -V    —— 期望 3.9 以上
git --version
```

如果 `python3` 命令不存在（Windows 常见），把下面所有 `python3` 换成 `py`。

### 0.1 先自检（强烈建议）· Run the preflight first

```bash
cd demo
python3 scripts/doctor.py          # 旧解释器也能跑，会直接告诉你该用哪条命令
```

它会检查：解释器版本 → 机器上是否已有更新的 Python → 依赖是否可导入 → 有没有中文字体。
**在 `pip install` 之前跑它，能省掉 90% 的环境问题。**

*Run `scripts/doctor.py` before `pip install`. It prints the interpreter, finds any newer Python already installed, checks the dependencies and the CJK font, and tells you the exact command to fix what is wrong.*

### 0.2 你遇到的那个报错 · The error you hit

```
Could not find a version that satisfies the requirement pydantic>=2.7
(from versions: 0.0.1, ..., 1.9.2)
No matching distribution found for pydantic>=2.7
```

**不是包的问题，是解释器太旧。** pip 在 Python 3.6 上只会列出 pydantic 1.9.x（2.x 要求 ≥3.7），
PyMuPDF 新版同样要求 3.9+，所以整条依赖链都会 "找不到版本"。

确认：

```bash
python3 -V          # 打出 3.6.x 就是它
```

四条修法，任选其一（**C 最稳**）：

| 方案 | 命令 | 适合 |
|---|---|---|
| **A 直接装 3.11** | `dnf install -y python3.11 python3.11-pip`<br>`python3.11 -m venv .venv && . .venv/bin/activate` | 有 root、能装源 |
| **B pyenv** | `curl -fsSL https://pyenv.run \| bash`<br>`pyenv install 3.11.9 && pyenv local 3.11.9` | 无 root，但能联网编译 |
| **C Docker（推荐）** | 见下方 §0.3 | 完全不碰系统 Python |
| **D conda** | `conda create -n chronik python=3.11 && conda activate chronik` | 已装 conda |

> 注意：**旧 venv 不能救活**。`python3.6 -m venv .venv` 建出来的环境里 pip 解析规则不变，
> 必须先有 3.9+ 的解释器，再 `python3.11 -m venv .venv`（建议删掉旧的 `.venv` 重建）。

### 0.3 完全不装 Python：用 Docker · Zero-install route

仓库根目录有 `docker-compose.yml`，镜像里是 Python 3.11 + 全部依赖：

```bash
cd ChronikShop            # 仓库根目录，不是 demo/
docker compose run --rm demo       # 双语
docker compose run --rm demo-en    # 全英文（给客户看的那份）
```

产物仍然落在宿主机的 `demo/out/`（CSV、复核页、PNG 卡片、指标）。
*Artefacts still land in `demo/out/` on your machine.*

## 2. 建虚拟环境 + 装依赖 · Virtualenv + dependencies

**macOS / Linux**

```bash
cd demo

source .venv/bin/activate

```

**Windows（PowerShell）**

```powershell
cd demo
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -q -r requirements.txt
```

> PowerShell 报"禁止运行脚本"时执行一次：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

不想用 venv 也可以直接 `pip install -r requirements.txt --user`，但建议用 venv。

- macOS：`open out/review/review.html`

> 中文标签需要系统里有 CJK 字体（Noto Sans CJK / 思源黑体 / PingFang / 微软雅黑）。找不到时会**自动退回英文**，不会画出空方块。

## 7. 常见问题 · Troubleshooting

| 现象 | 原因与解决 |
|---|---|
| `Could not find a version ... pydantic>=2.7` | 解释器太旧（多为 3.6）：见 §0.2 / `python3 scripts/doctor.py` |
| `ModuleNotFoundError: No module named 'chronik'` | 不在 `demo/` 目录里。命令必须在 `demo/` 下执行（`pymupdf` 不需要，但包路径需要） |
| `No module named 'pymupdf'` / `fitz` | 依赖没装或 venv 没激活：`pip install -r requirements.txt`（注意必须用 3.9+ 的 venv 装的 pip） |
| `RuntimeError: Chronik demo needs Python >= 3.9` | 我们主动拦下的：按提示里给的命令换解释器，或走 Docker |
| 复核页里没有截图 | 用了 `--no-crops`；去掉即可 |
| `FileNotFoundError: no recorded extraction for ...` | 你加了新的 PDF 但没有对应的 `fixtures/<文件名>.json`（离线模式下靠它回放模型输出）。要么走 `--live`，要么补一份 fixture |
| `out/` 里没有新 CSV | 该单被判定 `blocked`（缺 PO 号/客户/料号）。这是**有意设计**，看 `out/metrics.json` 的 `routes` |
| Windows 中文乱码 | `chcp 65001` 或改用 Windows Terminal；CSV 本身是 UTF-8 |
| 字体/表格错位（自己造样本时） | 只影响 `samples/*.pdf` 的观感，不影响流水线 |

## 9. 一分钟验证"它真的在做正确的事" · Prove it in one minute

跑完 `make demo` 后，打开 `out/review/review.html`，看 `fax_multipage.pdf` 那张卡片：

1. `DOC_LOW_QUALITY` —— 第 2 页是扫描图且被旋转了 90°，系统自动纠正并**压低置信度**
2. `SHIP_TO_AMBIGUOUS` —— 该客户地址簿里有两个几乎相同的 St Aidan 地址，系统**不猜**，交给人
3. `PRICE_MISMATCH` —— IV-2200 印的是 63.40，合同价 61.00，直接给差额
4. `TOTAL_MISMATCH` —— 单据总额与行合计对不上（这是"漏了一页"最常见的信号）

四类 flag 各自配一张原文截图 —— 这就是我们要卖给客户的东西。
