# 本地跑起来（10 分钟，零凭证）

> 目标：在你自己的电脑上跑通 `demo/`，看到 4 份订单 → CSV + 复核页 + 指标。
> 全程不需要 Azure 账号、不需要 API key、不需要联网（装依赖那一步需要联网）。

## 0. 你需要什么

- Python **3.9+**（3.11/3.12 都可以）
- Git
- 大约 300 MB 磁盘（大部分是 PyMuPDF 和 Pillow 的 wheel）

检查：

```bash
python3 -V      # Windows: py -V
git --version
```

如果 `python3` 命令不存在（Windows 常见），把下面所有 `python3` 换成 `py`。

## 1. 克隆仓库

git clone https://github.com/devops-huang/ChronikShop.git
cd ChronikShop

## 2. 建虚拟环境 + 装依赖

**macOS / Linux**

```bash
cd demo
python3 -m venv .venv
source .venv/bin/activate
pip install -q -r requirements.txt
```

**Windows（PowerShell）**

```powershell
cd demo
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -q -r requirements.txt
```

> PowerShell 报"禁止运行脚本"时执行一次：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

不想用 venv 也可以直接 `pip install -r requirements.txt --user`，但建议用 venv。

## 3. 跑一遍

```bash
python -m chronik.cli
```

预期输出（数值可能略有不同）：

```
document               route           conf  lines  flags
clean_po.pdf           auto_ready      0.99      6  —
fax_multipage.pdf      needs_review    0.86      5  DOC_LOW_QUALITY, PRICE_MISMATCH, SHIP_TO_AMBIGUOUS, TOTAL_MISMATCH
handwritten_po.pdf     needs_review    0.85      5  DOC_LOW_QUALITY, HANDWRITTEN, ITEM_MATCHED_BY_DESCRIPTION
unknown_format.pdf     blocked         0.43      4  EVIDENCE_UNVERIFIED, ITEM_NOT_FOUND, MISSING_PO_NUMBER, ...
```

然后看产物：

| 路径 | 看什么 |
|---|---|
| `demo/out/csv/PO_*.csv` | 每单一个 CSV（CRLF、UTF-8），直接给 ERP 用 |
| `demo/out/review/review.html` | **复核页**：每个 flag 旁边有原文截图 —— 用浏览器打开，这是给客户看的核心 |
| `demo/out/review/*.json` | 单证审计包：抽取结果 + 证据 + 置信度（可复现） |
| `demo/out/metrics.json` | 自动放行率、平均置信度、**每单成本**、flag 分布 |

打开复核页：

- macOS：`open out/review/review.html`
- Windows：`start out\review\review.html`
- Linux：`xdg-open out/review/review.html`

## 7. 常见问题

| 现象 | 原因与解决 |
|---|---|
| `ModuleNotFoundError: No module named 'chronik'` | 不在 `demo/` 目录里。命令必须在 `demo/` 下执行（`pymupdf` 不需要，但包路径需要） |
| `No module named 'pymupdf'` / `fitz` | 依赖没装或 venv 没激活：`pip install -r requirements.txt` |
| 复核页里没有截图 | 用了 `--no-crops`；去掉即可 |
| `FileNotFoundError: no recorded extraction for ...` | 你加了新的 PDF 但没有对应的 `fixtures/<文件名>.json`（离线模式下靠它回放模型输出）。要么走 `--live`，要么补一份 fixture |
| `out/` 里没有新 CSV | 该单被判定 `blocked`（缺 PO 号/客户/料号）。这是**有意设计**，看 `out/metrics.json` 的 `routes` |
| Windows 中文乱码 | `chcp 65001` 或改用 Windows Terminal；CSV 本身是 UTF-8 |
| 字体/表格错位（自己造样本时） | 只影响 `samples/*.pdf` 的观感，不影响流水线 |

## 8. 想改什么，改哪里

| 想改 | 文件 |
|---|---|
| CSV 列、列名、日期格式、文件名规则 | `config/settings.json` → `csv_spec` |
| 自动放行阈值 / blocked 是否也出 CSV | `config/settings.json` → `routing` |
| ERP 主数据 | `data/erp/*.csv`（客户/地址/物料/crosswalk） |
| 抽取 prompt | `chronik/prompts.py`（改完记得升 `PROMPT_VERSION`） |
| flag 规则、置信度上限 | `chronik/assess.py` 顶部常量 |
| 匹配阈值 | `chronik/matching.py` 顶部常量 |
| 复核页样式 | `chronik/review.py` 的 `CSS` |
| 架构图 | `docs/diagram/build_arch.py` → `python docs/diagram/build_arch.py --png` |

## 9. 一分钟验证"它真的在做正确的事"

跑完 `make demo` 后，打开 `out/review/review.html`，看 `fax_multipage.pdf` 那张卡片：

1. `DOC_LOW_QUALITY` —— 第 2 页是扫描图且被旋转了 90°，系统自动纠正并**压低置信度**
2. `SHIP_TO_AMBIGUOUS` —— 该客户地址簿里有两个几乎相同的 St Aidan 地址，系统**不猜**，交给人
3. `PRICE_MISMATCH` —— IV-2200 印的是 63.40，合同价 61.00，直接给差额
4. `TOTAL_MISMATCH` —— 单据总额与行合计对不上（这是"漏了一页"最常见的信号）

四类 flag 各自配一张原文截图 —— 这就是我们要卖给客户的东西。
